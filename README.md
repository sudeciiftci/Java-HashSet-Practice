Java HashSet Practice

This repository contains Java practice projects focused on the HashSet collection.

Projects

StudentManagementSystem

A simple student management example using HashSet.

Topics covered:

* HashSet
* add()
* contains()
* remove()
* Enhanced for loop

HashSet does not allow duplicate values, so adding "Sude" twice keeps only one "Sude".

CarRentalSystem

A simple car rental system that manages cars using their license plates.

Features:

* Add a car
* Remove a car
* Check whether a car exists
* Show available cars
* Count cars
* Exit the system

Topics covered:

* HashSet
* Scanner
* switch
* while loop
* add()
* remove()
* contains()
* isEmpty()
* size()

Technologies

* Java
* HashSet
* Collections
* Scanner
